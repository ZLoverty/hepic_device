# v0.3.x

## v0.3.0

- 主页 Dashboard 重新布局：挤出/回抽与温度设置合并为一组，急停按钮挪到更远的角落避免误触，新增「质检历史」侧栏面板（放大按钮字号，收紧面板宽度到刚好显示全部内容，历史条目做了单行显示避免换行）
- 质检历史改为持久化存储：
  - 后端新增 `GET /api/qc/history`（分页读取，默认最近 200 条）与 `POST /api/qc/history`（每次质检结束后由前端写入一条记录），落盘到 `HEPiC.database.QcHistoryStore`（SQLite），不再是重启即丢的内存列表
  - 前端启动时从 `/api/qc/history` 拉取历史记录填充侧栏，历史面板按日期分组显示（同一天的记录只显示一次日期标头）
- 修复质检历史面板与质检页面「冻结力值」显示不一致的问题：抽出共享的 `forceWindow.js`（滚动窗口最近 200 个样本、至少 10 个才出结果，逻辑对齐 HEPiC 的 `evaluate_force_window`），两处统一调用
- 正确处理 `ZERO_SENSORS` 指令：后端新增 `POST /api/klipper/zero_sensors`，对所有可清零传感器执行清零；前端监听到 M118 回传的 `ZERO_SENSORS` 文本时会调用该接口触发动作，而不是被后续的 `STOP_QUALITY_CHECK` 分支吞掉
- CI/CD：GitHub Actions 发布流程新增源码包（`git archive` 打包的纯源码，不含 `.git` 与 gitignore 掉的 `backend/static`）与 checksum 文件，并将静态前端包、源码包、checksum 三个产物同步镜像到腾讯云 COS，方便无法直连 GitHub 的树莓派设备下载；新增 `latest.json` 指针供设备解析「最新稳定版」，只有非预发布 tag 才会更新该指针
  - 新增 `scripts/fetch_src.sh`：优先从 COS 镜像、失败则回退到 GitHub Release 下载源码包，作为 `git clone` 的替代方案
  - `scripts/fetch_static.sh` 同步适配新的 COS 镜像与产物命名规则
  - 期间修复了一版产物命名不一致的问题（`hepic-device-<tag>-static/src.tar.gz` 统一改为 `hepic-device-static/src-<tag>.tar.gz`）
