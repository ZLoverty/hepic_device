# v0.2.x

## v0.2.0

- 材料属性数据库改为从独立仓库 [hepic_database](https://github.com/ZLoverty/hepic_database) 同步，更新材料参数不再需要重新发布/升级 hepic_device：
  - 启动时自动从 hepic_database 最新 Release 拉取 `materials.zip`，校验 checksum 通过后原子替换本地缓存目录；网络异常或校验失败时自动回退到已同步的本地缓存（或首次运行时的内置快照），不影响正常启动
  - 新增 `GET /api/materials/version` 接口，`GET /api/system/info` 增加 `material_db_version` 字段，方便快速确认当前设备跑的是哪个版本的材料库
  - 设置页「关于」区新增「材料库版本」展示
